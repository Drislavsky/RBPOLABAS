## 🎯 Описание проекта
**AutoService Management System** — это система управления автосервисом, предназначенная для учета клиентов, автомобилей, заказов на обслуживание и запчастей.  
Поддерживает роли, доступ через API, склад запчастей и создание сервисных заказов.

---

## 🏗️ Основные сущности

### **1. User (Пользователь)**
- Логин и пароль  
- Роли: **ADMIN**, **MECHANIC**, **CUSTOMER**  
- Может быть связан с Customer

### **2. Customer (Клиент)**
- Имя, email, телефон  
- Может иметь несколько автомобилей

### **3. Vehicle (Автомобиль)**
- Марка, модель, год выпуска, VIN  
- Привязан к владельцу (Customer)

### **4. Mechanic (Механик)**
- Имя, специализация  
- Выполняет заказы

### **5. Part (Запчасть)**
- Название, цена, количество  
- Категория, производитель, артикул  
- Учет наличия на складе

### **6. ServiceOrder (Заказ на обслуживание)**
- Клиент, автомобиль, механик  
- Список запчастей и задач  
- Статус выполнения  
- Общая стоимость

## 🚀 Основные операции

### 🔐 Аутентификация
- Регистрация пользователей  
- Авторизация через Basic Auth  
- Автоматическое создание администратора  

### 👥 Пользователи (ADMIN)
- Просмотр всех пользователей  
- Удаление пользователей  

### 🛠️ Запчасти (ADMIN / MECHANIC)
- CRUD операции  
- Управление складом (изменение количества)  
- Поиск по категории и производителю  
- Получение отчетов по складу  

### 🚗 Автомобили
- Добавление автомобилей  
- Привязка к клиентам  
- Просмотр списка автомобилей  

### 📋 Заказы
- Создание/закрытие заказов  
- Добавление/удаление запчастей  
- Отслеживание выполнения задач  
- Расчет итоговой стоимости  
- Фильтрация по статусам и клиентам  

### 👤 Клиенты и механики
- Управление профилями  
- Назначение механиков  
- Просмотр истории заказов  

---

## 🛡️ Роли и права доступа

### 🟩 **ADMIN**
- Полный доступ  
- Управление пользователями  
- Удаление любых данных  

### 🟦 **MECHANIC**
- Просмотр заказов и автомобилей  
- Управление складом  
- Выполнение задач по заказам  

### 🟨 **CUSTOMER**
- Создание заказов  
- Просмотр своих заказов  
- Добавление автомобилей
